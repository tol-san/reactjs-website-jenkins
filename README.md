# T-SHIRT SHOWCASE // 2026 ARCHIVE

A minimalist T-shirt showcase web application built with React and Vite.

## Design Philosophy

- **Light Mode**: Architectural white and subtle off-white tones (`#fafafa`, `#ffffff`) with ultra-fine border dividers.
- **Small Typography**: Scaled small font sizes (`9.5px` - `13.5px`) with high-tracking uppercase labels.
- **Google Fonts**: `Plus Jakarta Sans` for clean sans-serif text paired with `Space Mono` for technical numbers, weights, codes, and dimensions.
- **No Words of Persuasion**: Strictly objective catalogue and archive format. Zero marketing rhetoric, promo slogans, or sales prompts.
- **Authentic Imagery**: High-resolution photography sourced from [Unsplash](https://unsplash.com).

## Features

- **Grid & Table Views**: Seamlessly switch between 2-column, 3-column, 4-column cards, or an archival index table.
- **Cut & Tone Filters**: Filter specimens by silhouette (`BOXY`, `REGULAR`, `OVERSIZED`, `RELAXED`) and color palette (`LIGHT`, `DARK`, `NEUTRAL`, `EARTH`).
- **Detail Inspection Drawer**: Multi-angle views, technical yarn specifications, collar/hem construction data, and dimension matrix with unit switcher (`CM` / `IN`).

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run Oxlint
npm run lint

# Build production bundle
npm run build
```
